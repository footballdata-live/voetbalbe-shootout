# Levelmeting (tak `meting`)

Meet de pool van levelconfiguraties (`pool4.json`) met de physics van het spel, verdeeld over 20 parallelle jobs op GitHub Actions.
Een commit met `[meet]` in het bericht start de meting; het resultaat komt in `meting/uit/pool4_resultaat.jsonl`.
Deze tak raakt de speelbare versie (tak `main`, GitHub Pages) niet.
